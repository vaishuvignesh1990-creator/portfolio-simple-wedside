# # Personal Portfolio Website

A clean, responsive, two-page personal portfolio website built using **HTML5** and **CSS3**. Designed to showcase my background, featured projects, and provide a quick way to get in touch.

## 📄 Pages Included

* **Home Page (`index.html`)**: Introduces who I am, features my background, and highlights my primary projects and skills.
* **Contact Page (`contact.html`)**: Features a dedicated contact form and links to my professional social profiles.

## 🚀 Key Features

* **Clean Layout**: Built using core web standards for light and fast performance.
* **Responsive Design**: Uses CSS Flexbox/Grid and media queries for seamless viewing across mobile and desktop.
* **Interactive Navigation**: Simple site header allowing smooth navigation between Home and Contact pages.

## 🛠️ Built With

* **HTML5**: Semantic structure and page markup.
* **CSS3**: Custom styling, page layouts, and responsive design styles.
